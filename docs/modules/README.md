# Spesifikasi Modul (S7)

Satu file per modul setelah topic **S1, S2, S4, S5, S6** (dan **S3** untuk permission) memenuhi syarat freeze untuk modul tersebut.

Template: [`MODULE_SPEC_TEMPLATE.md`](./MODULE_SPEC_TEMPLATE.md)

Urutan disarankan:

1. `SETTINGS.md`
2. `IAM.md` (atau gabung settings)
3. `FINANCE.md` / `ACCOUNTING.md`
4. `INVENTORY.md`
5. `INQUIRY.md`
6. …

Status per file: `DRAFT` | `SEDANG_DIBAHAS` | `FREEZE`
